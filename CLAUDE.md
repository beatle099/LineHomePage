# Mishona PdM Checklist

## Project purpose
Interactive product development checklist for
Mishona (L Message SaaS). Single HTML file app.

## Stack
- Vanilla HTML + CSS + JavaScript, single file
- No build tools, no framework
- CSS variables only (no hardcoded colors)
- Dark mode must work at all times

## Rules
- All code lives in index.html
- Minimum font size: 11px
- Commit after each major feature
- Never hardcode colors — use CSS variables

## File Layout
```
LineHomePage/
  index.html       - Main app (checklist widget)
  CLAUDE.md        - Context for Claude Code
  AGENTS.md        - Context for Codex
  README.md        - Project documentation
  .gitignore       - Git ignore rules
```
