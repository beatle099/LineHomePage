## TIPS FOR BEST RESULTS

1. Use **ChatGPT-4o with DALL-E 3** for best quality
2. If result has unwanted text, add: "absolutely no text, no letters, no numbers"
3. For consistent style across all images, start a new chat and say:
   > "I am creating images for a Japanese hair salon called Haru Tokyo.
   > Brand colors: rose gold #c8846a, cream #fdf3ef, LINE green #06C755.
   > Style: warm, minimal, professional Japanese aesthetic.
   > Please remember this for all image requests in this conversation."
4. After generating, crop to exact pixel sizes using:
   - **Windows**: Paint / Photos app
   - **Mac**: Preview
   - **Online**: squoosh.app (free, resize + compress)
5. Save JPG at **80% quality** to keep file size under 100KB per image
